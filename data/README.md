# Synthetic local warehouse

ecommerce.db is generated by scripts/init_db.py with fixed-seed Faker data.
Money is integer USD cents. See docs/01-data-model.md for grain and integrity.
Database files are ignored by Git and reproducible from pinned generator packages.
No real customer data is used. Application connections are read-only.
The generator refuses to overwrite databases; use --path for a new output file.
